## Structure

- `index.html` : accueil et tableau de bord des matières
- Une page HTML indépendante par matière
- `style.css` : style commun à tout le site
- `script.js` : interactions du guide Blender

La page **Production 3D** contient actuellement le guide Blender et ses raccourcis. Les autres pages servent de bases prêtes à être enrichies avec les prochains cours.

## Utilisation

Le site est statique : ouvrir `index.html` suffit pour le consulter localement.

### GitHub Pages

Dans GitHub : **Settings → Pages → Deploy from a branch → main → /(root)**.
