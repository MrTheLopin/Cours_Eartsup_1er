# Blender — Guide E-artsup

Guide de référence rapide pour Blender, construit à partir des notes de cours.

## Contenu
- Interface en 4 îlots
- Propriétés : Object, Modifier, Physics, Animation, Data, Material
- Pipeline de rendu avec Cycles
- UV Editor et Shader Editor
- Préférences et LoopTools
- Raccourcis essentiels
- Recherche instantanée dans les raccourcis

## Utilisation
Le site est statique : ouvrir `index.html` suffit pour le consulter localement.

### GitHub Pages
Dans GitHub : **Settings → Pages → Deploy from a branch → main → /(root)**.

Le contenu est volontairement prévu pour être enrichi au fil du cours.
