02

Transmission du message — Shannon & Weaver

Trois dimensions opérationnelles : signal, code et bruit.

ConceptDéfinition & applicationCondition de succès
SignalForme physique, visuelle ou sonore : volume de voix, débit, posture, typographie, contraste, qualité d'image.Efficacité = Signal − Bruit. Le signal doit surpasser l'environnement.
CodeSystème de signes partagé. Verbal : vocabulaire, registre, syntaxe. Non-verbal : regard, gestuelle, ton, univers graphique.Code émetteur = code récepteur. Alignement entre signifiant et signifié.
BruitInterférences : physiques (lisibilité, surcharge, bruit ambiant), sémantiques (ambiguïtés, métaphores), psychologiques (a priori, fatigue, rejet).Identifier & neutraliser les perturbations.
Palo Alto

« On ne peut pas ne pas communiquer. » Tout comportement, silence, posture ou choix graphique produit du sens et communique une intention.

03

Les 6 fonctions du langage — Roman Jakobson

Conative

Récepteur · inciter, convaincre ou faire agir. Ex. ordres, CTA, slogans.

Expressive

Émetteur · émotions, opinions, croyances ou valeurs.

Poétique

Message · forme esthétique, rythme, beauté visuelle, créativité.

Référentielle

Contexte · faits, données, preuves et descriptions techniques.

Phatique

Contact · établir, maintenir ou vérifier la connexion avec l'auditoire.

Métalinguistique

Code · expliquer les termes ou symboles pour éviter les contresens.

Schéma à retenir

Contexte → Référentielle · Émetteur → Expressive · Message → Poétique · Récepteur → Conative · Contact → Phatique · Code → Métalinguistique

04

Analyse de l'impact — Lasswell

Question centrale

« Qui dit Quoi, par Quel canal, à Qui, avec Quel effet ? »

L'effet est la transformation mesurable constatée chez le récepteur.

01

Impact cognitif

Ce que l'auditoire apprend : compréhension et information.

02

Impact affectif

Ce que l'auditoire ressent : attitude, émotion ou perception.

03

Impact comportemental

Ce que l'auditoire réalise : action, adhésion ou décision.

05

Grille d'auto-évaluation

SIGNAL

Clarté

Votre message est-il parfaitement lisible ou audible ? Avez-vous supprimé les bruits parasitaires ?

CODE

Rigueur

Votre posture, vocabulaire et supports visuels sont-ils alignés avec votre intention ?

FONCTION

Intention

Quelle est la fonction principale ? Cherchez-vous à informer, émouvoir ou convaincre ?

À retenir

Vérifier le signal, le code et les bruits possibles ; identifier l'intention dominante ; définir l'effet concret recherché sur le récepteur.
