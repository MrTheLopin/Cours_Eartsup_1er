Théories de la communication

Objectif

Cette fiche récapitule les concepts fondamentaux de la communication humaine et des médias. Elle sert de grille de lecture pour analyser une situation de communication, diagnostiquer une campagne publicitaire ou préparer une prise de parole en public.

Impact

02

Transmission du message — Shannon & Weaver

Trois dimensions opérationnelles : signal, code et bruit.

ConceptDéfinition & applicationCondition de succès
SignalForme physique, visuelle ou sonore : volume de voix, débit, posture, typographie, contraste, qualité d'image.Efficacité = Signal − Bruit. Le signal doit surpasser l'environnement.
CodeSystème de signes partagé. Verbal : vocabulaire, registre, syntaxe. Non-verbal : regard, gestuelle, ton, univers graphique.Code émetteur = code récepteur. Alignement entre signifiant et signifié.
BruitInterférences : physiques (lisibilité, surcharge, bruit ambiant), sémantiques (ambiguïtés, métaphores), psychologiques (a priori, fatigue, rejet).Identifier & neutraliser les perturbations.
Palo Alto

« On ne peut pas ne pas communiquer. » Tout comportement, silence, posture ou choix graphique produit du sens et communique une intention.

03

Les 6 fonctions du langage — Roman Jakobson

Conative

Récepteur · inciter, convaincre ou faire agir. Ex. ordres, CTA, slogans.

Expressive

Émetteur · émotions, opinions, croyances ou valeurs.

Poétique

Message · forme esthétique, rythme, beauté visuelle, créativité.

Référentielle

Contexte · faits, données, preuves et descriptions techniques.

Phatique

Contact · établir, maintenir ou vérifier la connexion avec l'auditoire.

Métalinguistique

Code · expliquer les termes ou symboles pour éviter les contresens.

Schéma à retenir

Contexte → Référentielle · Émetteur → Expressive · Message → Poétique · Récepteur → Conative · Contact → Phatique · Code → Métalinguistique

04

Analyse de l'impact — Lasswell

Question centrale

« Qui dit Quoi, par Quel canal, à Qui, avec Quel effet ? »

L'effet est la transformation mesurable constatée chez le récepteur.

01

Impact cognitif

Ce que l'auditoire apprend : compréhension et information.

02

Impact affectif

Ce que l'auditoire ressent : attitude, émotion ou perception.

03

Impact comportemental

Ce que l'auditoire réalise : action, adhésion ou décision.

05

Grille d'auto-évaluation

SIGNAL

Clarté

Votre message est-il parfaitement lisible ou audible ? Avez-vous supprimé les bruits parasitaires ?

CODE

Rigueur

Votre posture, vocabulaire et supports visuels sont-ils alignés avec votre intention ?

FONCTION

Intention

Quelle est la fonction principale ? Cherchez-vous à informer, émouvoir ou convaincre ?

À retenir

Vérifier le signal, le code et les bruits possibles ; identifier l'intention dominante ; définir l'effet concret recherché sur le récepteur.

06

Atelier — Diagnostic communicationnel d'une campagne publicitaire

Objectif

Appliquer la grille de lecture du cours à une campagne : Signal, Bruit, Code, Rhétorique / fonctions de Jakobson, puis formuler une analyse critique et une recommandation.

Format de l'exercice

Travail en groupe sur une campagne attribuée, suivi d'une restitution orale de 5 minutes avec le support de présentation fourni.

01

Cadrage initial — La campagne & son environnement

Identifier l'annonceur / émetteur : marque, univers et promesse. Définir le public cible / récepteur : cible prioritaire, profil socio-démographique ou affinitaire. Préciser le canal de diffusion / média : affichage, réseaux sociaux, presse, TV, etc. Ajouter le visuel principal analysé.

02

Modèle de transmission — Signal, Code & Bruit

Signal physique : puissance visuelle ou sonore et qualité du signal. Code partagé : code verbal et non-verbal décodé par la cible. Bruit identifié : bruit physique, sémantique ou psychologique susceptible de faire échouer le message.

03

Intention & discours — Fonctions du langage

Identifier la fonction dominante et éventuellement une fonction secondaire parmi les six fonctions de Jakobson : expressive, conative, phatique, métalinguistique, référentielle, poétique. Justifier le choix en montrant comment la forme et le message orientent la réception.

04

Réception & ancrage — Effet produit

Évaluer les effets produits sur le récepteur et répondre à la question : « Le message atteint-il sa cible avec justesse ? » Formuler un bilan critique sur la portée réelle de la campagne auprès de son public.

05

Recommandation — « C'est qui le patron ? »

Se placer du point de vue de l'équipe créative / des directeurs artistiques et proposer ce qui serait modifié pour rendre la campagne plus mémorable. Terminer par un argument clé : une phrase percutante pour conclure le pitch avec autorité et conviction.

TRANSMISSION

Question à se poser

Le code est-il compréhensible par la cible ? Le signal est-il clair ? Le bruit perturbe-t-il le message ?

INTENTION

Question à se poser

Quelle fonction de Jakobson domine et pourquoi ? La forme du message soutient-elle cette intention ?

RÉCEPTION

Question à se poser

Quel effet la campagne cherche-t-elle à produire et quelle est sa portée réelle auprès de la cible ?

Structure rapide pour une analyse

Campagne → Émetteur → Cible → Média → Signal → Code → Bruit → Fonction dominante → Effets → Bilan → Recommandation.
